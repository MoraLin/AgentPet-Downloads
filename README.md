# Agent Pet 🦖

Your AI is working. Your pet knows.

Agent Pet is a macOS desktop companion that reacts to Claude Code activity. It shows different animations while Claude is working, waiting for your response, completing a task, or encountering an error.

> This repository contains public downloads only.
> The application source code is maintained separately.

## Download

Download the latest version from [GitHub Releases](https://github.com/MoraLin/AgentPet-Downloads/releases/latest).

### Apple Silicon Mac

For Macs with an Apple chip:

* M1
* M2
* M3
* M4
* M5

Download:

[⬇️ Agent Pet for Apple Silicon](https://github.com/MoraLin/AgentPet-Downloads/releases/latest/download/ClaudePet-1.0.0-arm64.dmg)

### Intel Mac

For older Macs with an Intel processor:

[⬇️ Agent Pet for Intel Mac](https://github.com/MoraLin/AgentPet-Downloads/releases/latest/download/ClaudePet-1.0.0-x64.dmg)

### Not sure which version to choose?

Open:

** Apple menu → About This Mac**

* If it says **Chip: Apple M1, M2, M3, M4, or M5**, choose Apple Silicon.
* If it says **Processor: Intel**, choose Intel Mac.

## Installation

1. Download the correct `.dmg` file.
2. Open the downloaded file.
3. Drag Agent Pet into the Applications folder.
4. Launch Agent Pet from Applications.

## Compatibility

* macOS 13 or later
* Claude Code in CLI, terminal, or VS Code
* No Node.js installation required

## Important

Agent Pet currently supports **Claude Code only**.

Claude Desktop is not supported because it does not provide the required hooks.

## Customize Your Pet

Agent Pet includes the official dinosaur skin by default. 🦖

You can also import compatible GIF pet packs from:

[Codex Pets](https://codex-pets.net/)

Right-click the desktop pet and select the appearance import option to switch characters.
