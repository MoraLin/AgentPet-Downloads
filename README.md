# Agent Pet 🦖

Your AI is working. Your pet knows.

Agent Pet is a desktop companion for macOS and Windows that reacts to Claude Code activity. It shows different animations while Claude is working, waiting for your response, completing a task, or encountering an error.

> This repository contains public downloads only.  
> The application source code is maintained separately.

### Not sure which Mac version to choose?

Open:

** Apple menu → About This Mac**

- If it says **Chip: Apple M1, M2, M3, M4, or M5**, choose Apple Silicon.
- If it says **Processor: Intel**, choose Intel Mac.

## Installation

### Windows

1. Download `Agent-Pet-win.exe`.
2. Open the installer and follow the setup instructions.
3. Launch Agent Pet from the Start menu or desktop shortcut.
4. If Windows SmartScreen appears, choose **More info → Run anyway** only when the file was downloaded from this repository.

### macOS

1. Download the correct `.dmg` file.
2. Open the downloaded file.
3. Drag Agent Pet into the Applications folder.
4. Launch Agent Pet from Applications.

## Compatibility

- Windows 10 or Windows 11
- macOS 13 or later
- Claude Code in CLI, terminal, or VS Code
- No Node.js installation required

## Important

Agent Pet currently supports **Claude Code only**.

Claude Desktop is not supported because it does not provide the required hooks.

**Codex agent integration is coming soon.**
